# تسبيح — صدقة جارية

موقع إسلامي ثابت (Static) باللغة العربية، مبني ليكون مساحة هادئة للأدعية والقرآن الكريم والمسبحة وأذكار الصباح والمساء وباب الخير، مع إمكانية إهداء العمل صدقة جارية عن اسم تحبه، ومشاركة الرابط ورمز QR.

- **لا خادم، ولا قاعدة بيانات، ولا حسابات، ولا تتبّع.**
- **لا تبرعات ولا روابط دفع.** صفحة «باب الخير» معلوماتية فقط.
- **كل شيء يعمل من ملفات ثابتة** يمكن نشرها مجانًا على GitHub Pages أو Cloudflare Pages.
- **البيانات المحلية** (الاسم، المفضلة، عدّاد المسبحة، تقدم الأذكار، تعديلات المحرر) تُحفظ في `localStorage` على جهاز الزائر فقط.

## التشغيل المحلي

لا تفتح `index.html` مباشرة بنقر مزدوج (`file://`)، لأن تحميل ملفات JSON وService Worker لا يعمل بهذه الطريقة. شغّل خادمًا محليًا بسيطًا:

### Python

```bash
cd sadka
python -m http.server 4173
```

ثم افتح:

```text
http://localhost:4173/
```

### Node.js

```bash
cd sadka
npx serve .
```

أو أي خادم ثابت آخر. المهم أن يكون الموقع مخدومًا عبر `http://localhost` أو `https://`.

> **ملاحظة:** إذا كان الخادم يخدم مجلدًا أبًا، فسيكون المسار مثل `http://localhost:4173/sadka/`. الموقع يدعم المسارات الفرعية (subpath) لأن جميع الروابط داخله نسبية.

### التحقق من سلامة JSON

```bash
node -e "['duas','quran','adhkar','charity','tasbeeh','site'].forEach(f=>{JSON.parse(require('fs').readFileSync('data/'+f+'.json','utf8'));console.log(f+'.json OK')})"
```

## المحتوى والمصادر

### القرآن الكريم

- النص بالرسم العثماني من **Tanzil Uthmani** عبر **Al Quran Cloud**.
- جميع الآيات الـ27 في `data/quran.json` تمت مطابقتها مع واجهة `quran-uthmani`.
- لا يُضاف نص قرآني من الذاكرة أو من مواقع غير موثوقة.
- الاستماع اختياري ولا يُحمّل الصوت إلا عند الضغط، من:

```text
https://cdn.islamic.network/quran/audio/128/ar.alafasy/{رقم الآية العام}.mp3
```

التلاوة للشيخ **مشاري راشد العفاسي**.

### الأدعية والأذكار

- الأدعية المأثورة من **صحيح البخاري** و**صحيح مسلم** و**السنن**، مع رقم الحديث ورابط `sunnah.com`.
- الأحكام من **الألباني** أو **دار السلام** حيث ينطبق، وتظهر بجانب الدعاء.
- الأدعية العامة التي لا يُنسب لفظها إلى النبي ﷺ موسومة بوضوح:
  - `type: "general"`
  - `source: "دعاء عام"`
  - ملاحظة توضح أنها صيغة عامة.
- لا يُعرض حديث ضعيف على أنه صحيح. استُبعدت أحاديث ضعيفة يعتمدها بعض المواقع، منها:
  - **سنن ابن ماجه 3684**
  - **سنن أبي داود 5072**
- استُخدم **سنن أبي داود 3221** لا 3223.

### تنبيهات دقة مقصودة

1. **ذكر «أصبحنا وأصبح الملك لله»** في أذكار الصباح:
   - الأصل في **صحيح مسلم 2723b** بلفظ المساء، وقال في آخره: «وإذا أصبح قال ذلك أيضًا: أصبحنا وأصبح الملك لله».
   - النص المعروض هو لفظ الحديث مع تبديل موضع الليل بالنهار، وقد ذُكر ذلك صراحة في حقل `note`؛ لأنه ليس لفظًا مستقلًا برواية أخرى.
2. **موضوع «النور والثبات»** في صفحة القرآن:
   - سُمّي بهذا الاسم بدل «النور في القبر» تجنبًا لنسبة لفظ لم يرد به نص قرآني صريح.
   - الآيات عن نور المؤمنين يوم القيامة (التحريم 8، الحديد 12)، ونور الهداية (الزمر 22)، والثبات عند سؤال القبر (إبراهيم 27، وقد ورد تفسيرها بذلك في صحيح البخاري 1369).
   - دعاء «اللهم اجعل قبره نورًا» موجود في قسم الأدعية بوصفه **دعاءً عامًا**، لا حديثًا مرفوعًا.

## إضافة أو تعديل الأدعية

الملف الأساسي: `data/duas.json`.

### بنية الملف

```json
{
  "version": 1,
  "updated": "2026-11-01",
  "note": "ملاحظة عامة عن المحتوى",
  "categories": [
    { "id": "mercy", "title": "الرحمة", "description": "..." }
  ],
  "duas": [
    {
      "id": "example-dua",
      "title": "عنوان الدعاء",
      "category": "mercy",
      "type": "hadith",
      "text": "نص الدعاء بالتشكيل...",
      "source": "صحيح مسلم",
      "reference": "963a",
      "grade": "صحيح",
      "sourceUrl": "https://sunnah.com/muslim:963a",
      "repeat": 1,
      "tags": ["المتوفى", "الرحمة"],
      "featured": false,
      "note": "ملاحظة توضيحية إن وجدت"
    }
  ]
}
```

### الحقول

| الحقل | مطلوب | الشرح |
|---|---|---|
| `id` | نعم | معرّف فريد بالإنجليزية، يُستخدم في رابط `#id`. لا تغيّره بعد النشر حتى لا تنكسر الروابط. |
| `title` | نعم | عنوان مختصر يظهر في البطاقة. |
| `category` | نعم | يجب أن يطابق `id` في مصفوفة `categories`. |
| `type` | نعم | `quran` أو `hadith` أو `general`. |
| `text` | نعم | النص العربي الكامل بالتشكيل. لا تُغيّر ألفاظ الحديث. |
| `source` | نعم | اسم المصدر، مثل «صحيح البخاري» أو «دعاء عام». |
| `reference` | نعم | رقم الحديث أو الآية أو «صيغة عامة». |
| `grade` | للحديث | «صحيح» أو «حسن» أو «حسن الإسناد»... واتركه فارغًا للدعاء العام. |
| `sourceUrl` | مستحسن | رابط التحقق على `sunnah.com` أو `quran.com`. |
| `repeat` | لا | عدد التكرارات، الافتراضي 1. |
| `tags` | لا | كلمات للبحث والتصفية. |
| `featured` | لا | `true` لجعله دعاء اليوم المميز. |
| `note` | لا | توضيح عن اللفظ أو الضمير أو التخريج. |

### إضافة تصنيف جديد

أضف كائنًا إلى `categories`:

```json
{ "id": "new-category", "title": "التصنيف الجديد", "description": "وصف مختصر." }
```

ثم استخدم `"category": "new-category"` في الدعاء. ستظهر خانة التصنيف تلقائيًا في صفحة الأدعية والمحرر.

### قواعد التحرير الديني

1. **لا تنسب إلى النبي ﷺ إلا نصًا ثابتًا** مع المصدر والرقم.
2. **الدعاء العام** يبقى عامًا: `type: "general"` و`source: "دعاء عام"`، ولا يُقال إن النبي ﷺ قاله.
3. **القرآن** يُنقل بالرسم العثماني من مصدر موثوق، دون إعادة صياغة.
4. **لا تُدرج حديثًا ضعيفًا** على أنه صحيح. إن أدرجته للتنبيه، فوضّح حكمه بوضوح.
5. **الضمائر**: كثير من أدعية الميت وردت بلفظ المذكر «له». إذا أضفت نسخة للمؤنث فاجعلها دعاءً عامًا أو وضّح التعديل في `note`.
6. **راجع الرابط** على `sunnah.com` قبل الحفظ.

### التحقق بعد التعديل

```bash
node -e "const d=JSON.parse(require('fs').readFileSync('data/duas.json','utf8')); console.log('duas:',d.duas.length,'categories:',d.categories.length)"
```

ثم أعد تحميل الصفحة مع `Ctrl+F5` (أو امسح الكاش) لأن Service Worker قد يخدّم نسخة قديمة من JSON عند العمل دون اتصال.

## المحرر المحلي ونشر التعديلات

المحرر في:

```text
/pages/editor.html
```

### ما يفعله

- يضيف ويعدّل ويحذف الأدعية **محليًا فقط**.
- يحفظ التغييرات في `localStorage` تحت المفتاح:

```text
tasbeeh.duas.overlay.v1
```

- يعرض شارة **«محلي»** على البطاقات المعدّلة في صفحة الأدعية.
- يصدّر ملف `duas.json` مدمجًا (الأساس + تعديلاتك) عبر زر **«تصدير duas.json»**.
- زر **«إعادة الضبط»** يمسح كل التعديلات المحلية.

### ما لا يفعله

- **لا ينشر شيئًا تلقائيًا.** التعديلات لا تظهر لزوار الموقع.
- **لا يرسل بيانات** إلى أي خادم.
- **لا يعدّل ملف `data/duas.json`** على القرص.

### خطوات النشر

1. افتح المحرر محليًا أو على نسختك المنشورة.
2. أضف/عدّل الأدعية.
3. اضغط **«تصدير duas.json»**.
4. استبدل `data/duas.json` في المشروع بالملف المصدّر.
5. تحقق من JSON ثم ارفع التغييرات إلى مستودع النشر.
6. بعد النشر، افتح الموقع مرة واحدة، ثم أعد تحميله بقوة عند الحاجة.

> **مهم:** ملف `duas.json` المصدّر يحتوي نسخة كاملة من الأدعية، وليس التعديلات فقط. لا تدمجه يدويًا مع الملف القديم؛ استبدله بالكامل.

## تعديل القرآن والأذكار

### `data/quran.json`

```json
{
  "id": "forgiveness",
  "title": "المغفرة",
  "subtitle": "توبة واستغفار...",
  "note": "ملاحظة اختيارية تظهر أسفل العنوان",
  "verses": [
    {
      "id": "2:286",
      "surahNumber": 2,
      "surah": "البقرة",
      "ayah": 286,
      "text": "النص العثماني...",
      "audio": 293
    }
  ]
}
```

- `audio` هو **رقم الآية العام** في المصحف، وليس رقمها داخل السورة.
- يمكن حذف `audio` لتعطيل الاستماع لهذه الآية.
- `note` اختياري ويظهر في صندوق تنبيه أسفل عنوان الموضوع.
- لا تغيّر `id` بعد النشر إن كان هناك روابط مشاركة تشير إليه.

### `data/adhkar.json`

```json
{
  "id": "morning",
  "title": "أذكار الصباح",
  "subtitle": "بداية يومك بذكر الله",
  "note": "ملاحظة عامة",
  "items": [
    {
      "id": "m-ayat-kursi",
      "title": "آية الكرسي",
      "text": "النص...",
      "repeat": 1,
      "type": "quran",
      "source": "سورة البقرة",
      "reference": "الآية 255",
      "grade": "",
      "sourceUrl": "",
      "note": ""
    }
  ]
}
```

- `repeat` يحدد عدد الضغطات المطلوبة لإتمام الذكر.
- `type`: `quran` أو `hadith` أو `general`.
- حافظ على النصوص كما وردت، خاصة الآيات.
- إذا أضفت ذكرًا جديدًا، تحقق من المصدر والحكم أولًا.

### `data/tasbeeh.json`

عبارات المسبحة وأهدافها. كل عبارة تحتوي `id` و`text` و`target` و`evidence` و`virtue`. يمكن إضافة عبارة جديدة، وستظهر تلقائيًا في المسبحة.

### `data/charity.json`

بطاقات باب الخير، والأفكار بلا مال، والنصائح، والتنبيه بعدم جمع التبرعات. عدّل النصوص بحرص، ولا تضف روابط دفع أو حسابات بنكية.

## الإهداء والمشاركة وQR

### كيف يعمل الإهداء

- يكتب الزائر الاسم في نافذة **«اجعل هذا العمل صدقة جارية عن»**.
- يمكن اختيار صفة القرابة (اختياري).
- يُحفظ الاسم محليًا، ويُضاف إلى رابط الصفحة:

```text
https://example.com/?name=فاطمة
https://example.com/?name=فاطمة&rel=mother
```

- عند فتح الرابط، يقرأ الموقع `name` و`rel` ويعرض الإهداء.
- الاسم وحده يعمل دون `rel`.
- إذا كانت قيمة `rel` غير معروفة، تُهمل ويبقى الاسم.
- إذا كان `name` مشوّهًا (مثل `%E0%A4%A`)، يتجاهله الموقع ويعرض الإهداء الافتراضي دون خطأ.

### صفات القرابة المدعومة

`father`, `mother`, `grandfather`, `grandmother`, `husband`, `wife`, `son`, `daughter`, `brother`, `sister`, `uncle-p`, `aunt-p`, `uncle-m`, `aunt-m`, `friend-m`, `friend-f`, `teacher-m`, `teacher-f`, `child-m`, `child-f`, `family`.

### ترميز الروابط

- الأسماء العربية تُرمّز تلقائيًا عبر `URLSearchParams` (مثل `%D9%81%D8%A7%D8%B7%D9%85%D8%A9`).
- المسافات تظهر `+` في الرابط، وهي صحيحة في query string.
- لا تُرمّز الرابط مرتين. استخدم زر **«نسخ الرابط»** أو **«مشاركة»** من الموقع.

### QR

- رمز QR يُنشأ محليًا في المتصفح بمكتبة `qrcode-generator` المستضافة ذاتيًا.
- لا يُشفّر `localhost` أو العناوين الخاصة.
- ترتيب تحديد الرابط العام:
  1. رابط عام محفوظ محليًا من نافذة QR.
  2. `siteUrl` في `data/site.json`.
  3. أصل النشر المكتشف تلقائيًا (إن لم يكن محليًا).
- إذا لم يوجد رابط عام، تظهر نافذة تطلب إدخال رابط النشر. بعد حفظه مرة واحدة، يُستخدم في المشاركة وQR.
- يمكن تنزيل QR كصورة PNG، ونسخ الرابط، ومسحه بالهاتف.

### إعداد رابط النشر مسبقًا

في `data/site.json`:

```json
{
  "siteUrl": "https://username.github.io/sadka/"
}
```

- ضع الرابط الكامل **بعد** النشر.
- يُفضّل أن ينتهي بـ `/`.
- لا تضع `localhost` أو `127.0.0.1`.
- إذا نشرت على نطاق مخصص، ضع النطاق المخصص.

## تطبيق الويب PWA

### الملفات

- `manifest.webmanifest`: الاسم، الأيقونات، الألوان، الاختصارات.
- `sw.js`: تخزين مؤقت للواجهة والملفات، واستجابة عند انقطاع الاتصال.
- `assets/images/icon-192.png` و`icon-512.png` و`icon-maskable-512.png` و`apple-touch-icon.png`.

### التثبيت

- **أندرويد (Chrome):** قائمة المتصفح ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **كمبيوتر (Chrome/Edge):** أيقونة التثبيت في شريط العنوان، أو «تثبيت تسبيح» من القائمة.

يظهر زر التثبيت داخل الموقع عند توفره، وإلا يفتح إرشادات التثبيت.

### العمل دون اتصال

- تُخزّن الصفحات الأساسية والخطوط وCSS وJS وJSON في الكاش بعد أول زيارة.
- الصفحات التي زرتها سابقًا تعمل دون اتصال.
- **الصوت لا يُخزّن**؛ الاستماع يحتاج اتصالًا.
- إذا انقطعت الشبكة أثناء فتح صفحة غير مخزّنة، تظهر صفحة `offline.html` المكتفية بذاتها.

### التحديث

- عند نشر إصدار جديد، يظهر شريط **«يتوفر إصدار جديد من الموقع»** مع زر **«تحديث»**.
- عند الضغط، يُفعّل الـService Worker الجديد ويُعاد تحميل الصفحة.
- **مهم للمطوّر:** عند تغيير ملفات الواجهة (HTML/CSS/JS) أو الأيقونات، ارفع رقم `VERSION` في `sw.js`:

```js
const VERSION = "1.0.1";
```

- ملفات JSON تُحدّث عبر network-first، لكن رفع الإصدار يضمن تحديث النسخة المخزّنة للعمل دون اتصال أيضًا.

## النشر

### GitHub Pages

1. أنشئ مستودعًا على GitHub، وارفع محتويات المشروع إلى الفرع `main` (أو `master`).
2. من المستودع: **Settings → Pages**.
3. اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)`.
5. احفظ، وانتظر دقيقة حتى يظهر الرابط:

```text
https://USERNAME.github.io/REPO/
```

6. ضع الرابط في `data/site.json`:

```json
{
  "siteUrl": "https://USERNAME.github.io/REPO/"
}
```

7. ارفع التعديل. بعدها يعمل QR والمشاركة بالرابط الصحيح حتى قبل أن يفتح الزائر نافذة QR.

**ملاحظات GitHub Pages:**

- الموقع يدعم النشر على مسار فرعي (`/REPO/`) لأن كل المسارات نسبية.
- إذا كان المستودع باسم `USERNAME.github.io`، يكون الرابط `https://USERNAME.github.io/`.
- HTTPS مفعّل تلقائيًا، لذا يعمل PWA.
- لا تحتاج إلى build command؛ الملفات جاهزة كما هي.
- إذا ظهرت مشكلة في ملفات معينة، أضف ملفًا فارغًا باسم `.nojekyll` في الجذر لمنع معالجة Jekyll.

### Cloudflare Pages

1. اربط المستودع في Cloudflare Pages.
2. اترك **Build command** فارغًا.
3. **Build output directory**: `/` أو اتركه فارغًا حسب الواجهة.
4. انشر، ثم ضع رابط `pages.dev` أو النطاق المخصص في `siteUrl`.

### استضافات أخرى

يعمل الموقع على أي استضافة ثابتة: Netlify، Vercel، Firebase Hosting، Surge، أو خادم Nginx. الشرط الوحيد هو تقديم الملفات كما هي عبر HTTPS (أو localhost للتطوير).

## الاختبارات والتحقق

تم اختبار الموقع يدويًا وآليًا قبل التسليم:

- **المحتوى:**
  - مطابقة 27 آية قرآنية مع `quran-uthmani`.
  - مطابقة 8 أدعية قرآنية مع النص القرآني.
  - مراجعة مراجع الأحاديث والأحكام على `sunnah.com`.
- **الوظائف:**
  - البحث والتصفية والمفضلة والنسخ والنسخ مع المصدر.
  - روابط واتساب وQR ونسخ الرابط.
  - فك تشفير QR آليًا ومطابقته للرابط العام.
  - تنزيل بطاقة الإهداء PNG بمقاس 1080×1350 وفك QR منها.
  - إضافة/تعديل/حذف/تصدير/إعادة ضبط في المحرر.
  - حفظ الاسم والمفضلة وعدّاد المسبحة وتقدم الأذكار بعد إعادة التحميل.
  - الروابط المشوهة و`rel` غير الصالح.
  - PWA: التثبيت، الكاش، العمل دون اتصال، وشريط التحديث.
- **التجاوب:** 320، 375، 390، 430، 768، 1024، 1366، 1920 بكسل دون تمرير أفقي.
- **وحدة التحكم:** لا أخطاء في الصفحات العادية. صفحة 404 نفسها تُصدر رسالة 404 للمستند في أدوات المتصفح، وهذا سلوك الخادم المتوقع وليس خطأ في الصفحة.

### فحص سريع بعد أي تعديل

1. افتح كل صفحة من القائمة.
2. جرّب البحث والتصفية والمفضلة.
3. جرّب نسخ دعاء ونسخه مع المصدر.
4. افتح QR وتأكد أن الرابط يبدأ برابط النشر وليس localhost.
5. نزّل بطاقة الإهداء وافتحها.
6. أضف دعاءً في المحرر وصدّره، ثم تأكد من ظهوره في صفحة الأدعية بشارة «محلي».
7. أعد تحميل الصفحة وتأكد من بقاء الاسم والعداد.
8. اختبر الوضع الداكن والفاتح، وعرض 320 بكسل.
9. امسح QR بالهاتف.

## إمكانية الوصول والأداء

- HTML دلالي، عنوان `h1` واحد لكل صفحة، وتسلسل عناوين منطقي.
- رابط «تخطَّ إلى المحتوى» في بداية الصفحة.
- دعم كامل للوحة المفاتيح: `Tab`، `Escape` لإغلاق القوائم والنوافذ، وتركيز واضح.
- خصائص ARIA للقوائم والتبويبات والعدادات والرسائل الحية.
- احترام `prefers-reduced-motion`.
- تباين ألوان مناسب في الوضعين الفاتح والداكن.
- خطوط عربية مستضافة ذاتيًا، بلا طلبات لشبكات إعلانات أو تتبّع.
- الصوت لا يُحمّل إلا عند الطلب.
- لا صور نقطية ثقيلة في الواجهة؛ الأيقونات SVG.
- Service Worker يخزّن الأصول الأساسية لتسريع الزيارات المتكررة.

## ملاحظات دينية مهمة

- هذا الموقع أداة تذكير ودعاء، وليس مرجعًا فقهيًا. للفتوى راجع أهل العلم.
- **لا يُنسب لفظ إلى النبي ﷺ إلا بحديث ثابت**، مع المصدر والرقم والحكم.
- **الدعاء العام** ليس حديثًا، ويُوسم دائمًا بذلك.
- **القرآن** بالرسم العثماني، والاختيار الموضوعي للآيات اجتهاد للتدبّر وليس تفسيرًا ملزمًا.
- **الأحاديث الضعيفة** لا تُعرض كصحيحة. إذا وردت للإشارة، يُوضّح حكمها.
- **لا تجمع الصفحة تبرعات**، ولا تعرض أرقام حسابات أو روابط دفع. صفحة «باب الخير» أفكار فقط.
- **الاسم في الرابط** قد يظهر لمن تشاركه معه؛ لا تكتب ما لا ترغب في ظهوره. لا يُرسل الاسم إلى خادم.

## حل المشكلات

| المشكلة | الحل |
|---|---|
| الصفحة فارغة أو JSON لا يُحمّل | شغّل خادمًا محليًا (`python -m http.server`) ولا تفتح `file://`. |
| QR يطلب رابطًا عامًا | ضع `siteUrl` في `data/site.json`، أو أدخل رابط النشر مرة واحدة في نافذة QR. |
| QR يشير إلى localhost | لا يُسمح بذلك. استخدم رابط النشر العام. |
| التعديلات لا تظهر | أعد التحميل بقوة (`Ctrl+F5`)، أو امسح الكاش. للـPWA ارفع `VERSION` في `sw.js`. |
| PWA لا يُثبّت | تأكد من HTTPS أو localhost، ومن عدم استخدام نافذة خاصة. |
| الخطوط لا تظهر | تأكد من وجود ملفات `assets/fonts/` ومن مسار `assets/css` الصحيح. |
| الاسم العربي في الرابط يبدو مشوّهًا | استخدم زر النسخ من الموقع؛ لا ترمّز الرابط يدويًا مرتين. |
| المحرر لا يحفظ | تأكد من أن `localStorage` مفعّل، وأنك لا تستخدم وضع التصفح الخاص. |
| بطاقة الإهداء لا تُنزّل | تأكد من دعم المتصفح لـ`canvas.toBlob` ومن عدم حظر التنزيلات. |
| 404 تظهر في وحدة التحكم | طبيعي: المستند نفسه يعيد 404. الصفحة تعمل بلا أخطاء أصول. |
